## 🚀 Быстрый запуск и просмотр

1. **Локальный веб-сервер**:
   ```bash
   py -m http.server 3000
   ```
   Откройте в браузере: `http://localhost:3000`

2. **Деплой в продакшн**:
   - **Vercel / Cloudflare Pages**: перетащите папку проекта в дашборд и подключите кастомный домен.
   - **GitHub Pages**: загрузите кодовую базу в репозиторий `RomanMR7/roman-portfolio`.
